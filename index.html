I'm a final-year Computer Science and Engineering student at BAIUST, splitting my time between building full-stack JavaScript applications and grinding competitive programming problems in C++.

On the web side, I work across the stack — React and Vite on the frontend styled with Tailwind CSS, and Node.js, Express and MongoDB on the backend, usually with Mongoose handling the data layer.
